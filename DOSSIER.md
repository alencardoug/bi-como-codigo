## 7. Where I hesitated

Decisions that could have gone the other way, with the reason they went this one.

1. **One Python module for every step**, rather than shell in the workflows: each condition is
   testable without the network, and the workflows stay thin.
2. **`admit` finds the PR by `commits/{head}/pulls`** rather than by `workflow_run.pull_requests`,
   which GitHub leaves empty for forks and is not documented as authoritative.
3. **`decide` ends green with "nothing to promote"** for a direct push or a stale run, red for
   everything else; `check-tip` in `promote` ends red.
4. **The served-bytes check decodes only `gzip`** and refuses any other `Content-Encoding`.
5. **`verify` finds the package as the one `manifest.json`** in the artifact, and checks the data
   keys and their hex form by content in every file.
6. **The release record artifact is kept 30 days**, the channel's life.
7. **`release/firebase-tools/package-lock.json`** (290 KB) is committed so that the CLI is the same
   bytes at every run.
